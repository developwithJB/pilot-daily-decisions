# ADR 0003: Keep generative image and 3D providers off by default

Status: accepted.

Exact garment composition is the trustworthy baseline. Live image generation and 3D avatar generation are independent, server-enforced flags with deterministic mock or disabled adapters. The UI must identify generic fixtures and disclose that output is not body measurement, garment physics, or fit simulation. Production providers require private inputs, provenance, expiry, deletion, and isolation review before activation.
