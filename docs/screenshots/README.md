# Screenshot checklist

Release screenshots should cover Today, Week, Try On, Closet scan/correction, History, guided onboarding, Settings/connections, and the disclosed 3D viewer at 390×844 and 1440×900. Use only deterministic sample data. Do not capture real names, calendar details, personal photos, access tokens, signed URLs, or browser extensions. Store optimized WebP or PNG files here and include alt text in the README.
