# Code of conduct

We are committed to a respectful, harassment-free project for everyone. Be constructive, assume good intent, respect privacy and consent, and critique ideas or code rather than people. Harassment, discriminatory language, threats, doxxing, and publishing another person's private data are not acceptable.

Maintainers may edit or remove contributions and restrict participation when behavior threatens people, the community, or user safety. Report conduct concerns privately through the repository maintainers. Reports will be handled as confidentially as practical, with fair review and proportionate action.
